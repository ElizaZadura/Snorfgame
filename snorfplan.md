Build an interactive .snorfmap / .snorfgame based on the provided snorfmap and .snorfmap images.

Do not default to a simple browser card/menu if a richer medium would serve the concept better. Choose the stack/engine that best supports beauty, motion, atmosphere, and exploration.

This is allowed to be ambitious. The previous games were quick/minimal; this one should go all out.

Prioritize:
- visual beauty
- drifting/flowing transitions
- atmospheric motion
- same named regions as the .snorfmap image
- Snorf as a central gravity well
- idle user slowly pulled toward Snorf
- regions that open, reject, redirect, or transform
- map-world feeling, not menu/page feeling
- hidden paths / strange returns
- clear project notes and next steps

Use browser, game engine, canvas/WebGL, Godot, Unity, or any other approach.
Do not reduce this to simple clickable cards.

A bit of history is available in the ref folder. It's very difficult to capture all the accumulated snorflore, though, so I won't try too hard. Snorf.md is how and where it started. Another interesting ref might be https://www.snorfctionary.com
